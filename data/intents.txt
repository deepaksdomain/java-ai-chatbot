# ---------------- Computer science ----------------

[java]
patterns: what is java | tell me about java | why use java | what is java used for | is java hard to learn
responses: Java is an object-oriented language released by Sun Microsystems in 1995. Its motto is "write once, run anywhere" because code runs on the Java Virtual Machine (JVM). | Java powers Android apps, enterprise back-end systems and big data tools. It is strongly typed and object-oriented, which keeps large programs organized.

[oop]
patterns: what is oop | what is object oriented programming | explain oop | what are the pillars of oop | four pillars of oop
responses: Object-oriented programming (OOP) organizes code into objects that bundle data and behavior. Its four pillars are encapsulation, abstraction, inheritance and polymorphism. Ask me about any of them!

[encapsulation]
patterns: what is encapsulation | explain encapsulation | encapsulation
responses: Encapsulation means keeping an object's data private and only changing it through methods. My UserProfile class does this: its fields are private and it hands out copies, never the real list.

[inheritance]
patterns: what is inheritance | explain inheritance | inheritance
responses: Inheritance lets a class reuse code from a parent class. My MathSkill, TimeSkill and MemorySkill all extend the abstract Skill class.

[polymorphism]
patterns: what is polymorphism | explain polymorphism | polymorphism
responses: Polymorphism means one interface, many forms. I call skill.tryRespond() the same way on every skill, and each one runs its own code. I can also swap matching algorithms while running.

[abstraction]
patterns: what is abstraction | explain abstraction | abstraction
responses: Abstraction means exposing what something does and hiding how it does it. My IntentMatcher interface says "find the best matches" without saying which algorithm to use.

[data_structure]
patterns: what is a data structure | what are data structures | explain data structures | why are data structures important
responses: A data structure is a way of organizing data so it can be used efficiently. Examples include arrays, linked lists, stacks, queues, hash maps, trees and graphs. I use several of them myself!

[stack]
patterns: what is a stack | explain stack | how does a stack work | stack data structure
responses: A stack is Last-In-First-Out (LIFO), like a stack of plates. You push onto the top and pop off the top. I use two stacks to solve math problems with the Shunting-Yard algorithm!

[queue]
patterns: what is a queue | explain queue | how does a queue work | queue data structure
responses: A queue is First-In-First-Out (FIFO), like a line at a coffee shop. I keep our recent conversation in a queue: when it's full, the oldest message leaves first.

[hashmap]
patterns: what is a hashmap | what is a hash map | what is a hash table | explain hashmap | how does hashing work
responses: A hash map stores key-value pairs. A hash function turns each key into an array index, so lookups take O(1) time on average. I use hash maps for my word index and to remember things about you.

[heap]
patterns: what is a heap | what is a priority queue | explain heap | how does a heap work
responses: A heap is a tree where the parent is always smaller (min-heap) or larger (max-heap) than its children, so the top item is always the smallest or largest. Java's PriorityQueue is a heap. I use one to find my top 3 best guesses.

[linked_list]
patterns: what is a linked list | explain linked list | linked list vs array | how does a linked list work
responses: A linked list is a chain of nodes where each node holds a value and a pointer to the next node. Adding or removing at the front is O(1), but finding the 10th item means walking the chain, which is O(n). An array is the opposite: O(1) to read any index, but slow to insert in the middle.

[algorithm]
patterns: what is an algorithm | explain algorithms | what are algorithms | give me an example of an algorithm
responses: An algorithm is a step-by-step procedure for solving a problem. I use edit distance (dynamic programming) to fix typos, TF-IDF with cosine similarity to understand you, and a heap to rank my best guesses.

[big_o]
patterns: what is big o | what is big o notation | explain time complexity | what is time complexity | what is space complexity
responses: Big O notation describes how an algorithm's running time or memory grows as the input grows. O(1) is constant, O(log n) is logarithmic, O(n) is linear and O(n^2) is quadratic.

[dynamic_programming]
patterns: what is dynamic programming | explain dynamic programming | what is memoization
responses: Dynamic programming solves a big problem by breaking it into overlapping smaller problems and saving each answer so it is never computed twice. I use it to measure how far a typo is from a real word.
